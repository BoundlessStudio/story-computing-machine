# Glossary

## Galactic Cycle

- Status: LOCKED
- Summary: One orbit of the world's star system around the galactic center,
  used as the universal timeline's largest standard chronological unit.
- First established: user decision, 2026-07-22 (`sources/decisions/2026-07-22-universe-grill.md` Q036)
- Aliases: None
- Notes: Capitalize when naming the formal unit. It is not a synchronized cycle
  of civilizational rise and collapse.

## Magic, technology, and divinity

- Status: LOCKED
- Summary: Lowercase cultural labels for underlying systems, not objective
  cosmological categories.
- First established: user decision, 2026-07-22 (`sources/decisions/2026-07-22-universe-grill.md` Q013–Q014)
- Aliases: None
- Notes: Use the vocabulary appropriate to the viewpoint culture. Private canon
  should describe mechanisms rather than assume these labels define reality.

## Modern-like era

- Status: CANON
- Summary: The low-magic era associated with Nell and Bash that resembles
  contemporary Earth without necessarily being literal real-world Earth.
- First established: user decision, 2026-07-22 (`sources/decisions/2026-07-22-universe-grill.md` Q003, Q006)
- Aliases: Earth era; Nell and Bash era
- Notes: Its exact Galactic Cycle coordinate is unresolved.

## Ravel

- Status: CANON
- Summary: The Ravel setting belongs to another era of the same physical world
  as the modern-like and Glass-Sea settings, not to a separate planet or plane.
- First established: user decision, 2026-07-22 (`sources/decisions/2026-07-22-universe-grill.md` Q002, Q005,
  Q071)
- Aliases: None
- Notes: Its chronological position and all additional Ravel details remain
  unresolved unless established by another authoritative entry.

## Gate Cant

- Status: CANON
- Summary: A Ravel operating form attested at the Glass Gate by the bounded
  severance command “Living road, release the held path.”
- First established: stories/the-small-moon-rose-first/05-story.md
- Aliases: None
- Notes: The witnessed command requires living breath and stored charge and can
  sever an active path; it does not establish universal language-magic or
  name-magic.

## Temporal anchor

- Status: CANON
- Summary: For the Glass Gate, a living traveler's private remembered departure
  can serve as the crossing's return reference.
- First established: stories/the-small-moon-rose-first/05-story.md
- Aliases: Glass Gate temporal anchor
- Notes: Separate travelers' anchors produced separate return dates in the
  witnessed crossing. The term is Gate-specific and does not define a general
  rule for time travel.

## Identity-line

- Status: CANON

- First established: stories/the-small-moon-rose-first/05-story.md

- Notes: The term belongs to a bounded Ravel infrastructure operated through
  living agency; it is not a universal property of names or identity.

## Road name

- Status: CANON
- Summary: A deliberately limited character-facing identity used by Ravel
  travelers under threat from the Regent identity system.
- First established: stories/the-small-moon-rose-first/05-story.md
