# Bundled fonts

The unmodified WOFF2 font bytes come from Adobe's official release branches;
filenames omit the upstream `.ttf` infix. Corresponding OFL licenses are stored
alongside them. Font bytes are committed to pin the edition layout.

- Source Serif 4 Regular, Italic, Bold: https://github.com/adobe-fonts/source-serif/tree/release/WOFF2/TTF
- Source Sans 3 Regular, Semibold: https://github.com/adobe-fonts/source-sans/tree/release/WOFF2/TTF
