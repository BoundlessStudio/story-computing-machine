# Prose drafting

Use only for `CREATE_DRAFT` or `REVISE_DRAFT`. Require the prompt, current canon brief and authority inventory, scene-ready plan, cleared name inventory, and any assigned review findings.

Write only `stories/<slug>/03-draft.md`. Deliver complete prose at the requested length, POV, tense, tone, and rating. Preserve canon constraints and ensure every planned causal beat earns the next. Revision mode resolves the assigned findings and records each disposition; it does not restart the story or silently change the plan.

Do not edit final prose, canon delta, review history, registry, lifecycle records, or universe notes. Return the exact handoff change report.
