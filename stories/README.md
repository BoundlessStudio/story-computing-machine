# Stories

A new `[WP]` package uses `prompt.md`, `story.md`, and `notes.md`. The prompt preserves the user's request. The story is the reader-facing prose. The notes preserve the editorial conversation and why important changes were made. An outline, cover, or selected `art/` images are optional and should earn their place.

Older packages keep their existing four-file or bundle layout. Their `outline.md` and `review.md` remain history; do not rewrite them just to match a new template. A substantive authorized edit can add `notes.md` for the new discussion. Current stories mark canon in `story.md` frontmatter; bundles use `story.json`. Check the marker before editing. See [AGENTS.md](../AGENTS.md) for permissions and [story-create](../.agents/skills/story-create/SKILL.md) for the editorial practice.

`NAMES.md` is older name memory. It can help avoid confusing reuse, but neither it nor an old review establishes a universe fact. Shared facts belong to [universe/](../universe/README.md).
