# Existing illustrated editions

The six edition packages in this directory are preserved as authored artifacts: their prompts, plans, selected images, covers, edition data, and prose-preserving `edition.html` files remain in Git. They do not change their source stories or establish shared-universe facts.

The former Python, npm, Pages, and publication workflow has been retired so story writing can take priority. `STYLE.md` records the art and layout direction used for these editions; it is historical reference, not an active production contract. Existing `edition.html` files refer to assets from the retired site and are not guaranteed to work as standalone local readers. Their artwork and text remain available in the packages and Git history.

A new illustrated edition or repair to an existing reader is a separate, named request. Preserve the source story and its canon state, and decide its presentation method for that request rather than restarting the old pipeline.

The former site assets remain in the `codex/backup-main-2026-09-27` backup branch if a reader needs repair.
