# Existing graphic novels

The packages here preserve their plans, references, page images, covers, and final PDFs where completed. They are adaptations of named stories, not changes to the source prose or universe authority. Open an `edition.pdf` directly to read a completed book.

The former Pages capture and draft production workflow has been retired. `STYLE.md` records the visual direction of the existing books as historical art guidance. New graphic-novel work is a separate, named request; it should start from the source story and the user's current creative direction rather than a publication script.
